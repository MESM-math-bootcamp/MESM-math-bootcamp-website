# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A Quarto website (`project: type: website`) containing the materials for the **Bren Calculus Workshop**, a 5-day math primer taught during MESM orientation week at UCSB's Bren School. Content is R-flavored Quarto (`.qmd` with inline `` `r ...` `` and `library(tidyverse)`/`ggplot2`/`DT` chunks), not a software application — there is no test suite, linter, or package manifest (no `renv.lock`/`DESCRIPTION`).

## Commands

- Render the whole site: `quarto render` (outputs to `docs/`, per `output-dir` in `_quarto.yml`)
- Live-preview while editing: `quarto preview`
- Render/preview a single page: `quarto render notes/day2_limits/lecture-limits.qmd` or `quarto preview notes/day2_limits/lecture-limits.qmd`
- `execute: freeze: auto` is set globally, so R chunks only re-execute when their source changes — cached results live in `_freeze/`. If output looks stale after an edit, delete the corresponding subfolder under `_freeze/` (or run `quarto render --execute`) to force a re-run.

## Architecture

- `_quarto.yml` is the single source of truth for site structure: navbar, the docked sidebar (which lists every page in nav order), the announcement banner (currently a "under construction" notice), and HTML theme (`meds-website-styles.scss`).
- Content lives under `notes/`, one folder per workshop day: `day1_algebra/`, `day2_limits/`, `day3_derivatives/`, `day4_integrals/`, `day5_differential_equations/`. Each follows the same pattern:
  - `dayN_topic.qmd` — short landing page (linked from the sidebar) that links out to the three files below
  - `lecture-*.qmd` — the actual revealjs slide deck for that day (the largest files, 500–1400 lines)
  - `problem_set_*.qmd` / `solutions_problem_set_*.qmd` — exercises and answer key
  - `images/` — figures scoped to that day, referenced by relative path from the day's `.qmd` files
- `_planning/` holds instructor-facing planning notes and materials that core-course instructors (ESM 201/202/203/204) shared to inform what math content this workshop should cover — not site content, never linked from `_quarto.yml`. This folder is gitignored. See "Core courses this workshop supports" below for what's in it.

## Core courses this workshop supports

This workshop exists as a math primer for four MESM core courses. Per `_planning/MESM Calculus workshop planning.pdf` (instructor input collected while scoping content), each has a different, narrow set of math needs — content should be built to match these, not to teach calculus comprehensively:

- **ESM 201 (Ecology of Managed Ecosystems, Ashley Larsen):** basic algebra, exponents/fractions, `dn/dt` notation and `(1/N)(dn/dt)`, simple derivatives/differentiation, and reading terms in differential equations. 
- **ESM 202 (Environmental Biogeochemistry, Alexandra Phillips):** unit conversions are the single most important skill — ppm↔percent, mL↔L. This is the instructor's top priority, more than any calculus topic.
- **ESM 203 (Earth System Science, Jasechko/Caylor):** mass balance calculations and unit conversions (especially area units) are where students struggle. 
- **ESM 204 (Economics of Environmental Management, Anna Pede):** in order of importance — (1) reading graphs, (2) simple algebra, (3) simple derivatives (power rule, chain rule, log properties). Students especially struggle with understanding *why* a calculation is being done (e.g., integral = area under a curve = economic surplus), not just executing it.

`_planning/ESM_203_materials/` and `_planning/ESM_204_materials/` contain real quizzes/homework (with solutions) from those courses — these can be used as a source of realistic worked examples when writing new slide content or exercises, per the topic→example mapping also in the planning PDF.

- `_freeze/` is Quarto's execution cache (one subtree per rendered `.qmd`, mirroring the `notes/` layout) — treat it as a build artifact, not hand-edited content.
- `docs/` is the rendered site output that GitHub Pages actually serves; it's regenerated by `quarto render` and shouldn't be hand-edited either.
- Root-level `.scss` files (`meds-website-styles.scss`, `meds-slides-styles.scss`, `ucsb-media.scss`) hold the site/slide theming; `meds-slides-styles.scss` and `ucsb-media.scss` are pulled into individual lecture decks via their per-file `format.revealjs.theme` front matter, separately from the site-wide `meds-website-styles.scss` set in `_quarto.yml`.
