# Core courses this workshop supports

This workshop exists as a math primer for four MESM core courses. Per `_planning/MESM Calculus workshop planning.pdf` (instructor input collected while scoping content), each has a different, narrow set of math needs — content should be built to match these, not to teach calculus comprehensively:

- **ESM 201 (Ecology of Managed Ecosystems, Ashley Larsen):** basic algebra, exponents/fractions, `dn/dt` notation and `(1/N)(dn/dt)`, simple derivatives/differentiation, and reading terms in differential equations.
- **ESM 202 (Environmental Biogeochemistry, Alexandra Phillips):** unit conversions are the single most important skill — ppm↔percent, mL↔L. This is the instructor's top priority, more than any calculus topic.
- **ESM 203 (Earth System Science, Jasechko/Caylor):** mass balance calculations and unit conversions (especially area units) are where students struggle.
- **ESM 204 (Economics of Environmental Management, Anna Pede):** in order of importance — (1) reading graphs, (2) simple algebra, (3) simple derivatives (power rule, chain rule, log properties). Students especially struggle with understanding *why* a calculation is being done (e.g., integral = area under a curve = economic surplus), not just executing it.

`_planning/ESM_203_materials/` and `_planning/ESM_204_materials/` contain real quizzes/homework (with solutions) from those courses — these can be used as a source of realistic worked examples when writing new slide content or exercises, per the topic→example mapping also in the planning PDF.
